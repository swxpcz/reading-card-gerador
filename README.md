# Template de Leitura | Criado por Lucas Menegon

Gerador simples de templates para compartilhar a leitura atual.

## Arquivos

- `index.html`
- `style.css`
- `script.js`

## Como usar

Abra o `index.html` no navegador.

1. Digite o título.
2. Escolha a capa do livro.
3. Ajuste o progresso.
4. Escolha Story ou Quadrado.
5. Clique em "Baixar PNG".

O PNG é gerado no próprio navegador.
